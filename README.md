# 猜數字：第一個 Node.js 程式

一個適合初學者的繁體中文命令列遊戲，不需要安裝任何第三方套件。

## 開始使用

先安裝 Node.js 22 或更新版本，接著在終端機執行：

```sh
git clone https://github.com/shinjia/site_1020.git
cd site_1020
npm start
```

程式會隨機選出 1～100 的整數。輸入答案後，依照「太大了」或「太小了」的提示繼續猜，答對後會顯示猜測次數。輸入 `q` 或按 Ctrl+C 可離開。無效輸入不計入次數。

## 執行測試

```sh
npm test
```

## 從程式學習

- `const` 和 `let`：儲存答案與猜測次數。
- 函式：將輸入驗證與比較邏輯分開。
- `if`：根據猜測結果顯示提示。
- `while`：重複詢問直到答對或離開。
- `async/await`：等待使用者輸入。
- Node.js 內建測試工具：驗證輸入範圍與提示。

主要程式是 `guess-number.js`，測試是 `guess-number.test.js`。

## 練習挑戰

1. 把範圍改成 1～1000，並同步修改輸入驗證與說明。
2. 增加最多只能猜 7 次的規則。
3. 答對後詢問是否再玩一次。
